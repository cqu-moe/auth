# 第一方应用各自持有隔离的会话

普通第一方网站遭到入侵时，攻击者不能仅凭该站的应用会话直接接管中央账号或其他应用。为满足这一目标，采用各站独立会话，接受中央登录已建立后的一次自动登录跳转；登录协议、Cookie 迁移与全局退出机制将在后续设计中确定。

这一决定优先保证应用间隔离，接受接入和退出管理的额外成本。后台 Worker RPC 使用受限服务身份，其权限与用户会话分开，见 [私有 RPC 服务身份](./0009-private-rpc-service-identity.md)。

单个第一方网站的“退出登录”只结束本站会话，保留中央登录和其他站点会话，并停留在已退出页面；用户主动点击登录后才重新使用中央登录状态接回。“退出全部设备”是另一个明确操作，不与单站退出混用。

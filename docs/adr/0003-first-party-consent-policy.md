# 第一方应用默认开放，管理员通过权益控制使用

所有第一方应用默认向用户开放，无需用户逐个开通或授权，免 OAuth 同意页，也不提供用户单独停用第一方授权的开关。管理员通过业务权益控制用户是否能使用相应应用，以及可用功能和额度。这保留第一方产品的一体化体验；应用身份和权限上限仍由平台审批，第三方接入不继承这一待遇。

不建设用户对第一方应用的开通、授权开关或“撤销后重新启用”流程；协议需要的用户绑定令牌和授权记录不等于这样的产品开关。权益控制由具备对应管理权限的管理员执行，沿用现有权限层级；此决定不扩大应用自身获批权限，不使应用会话跨站通用。

退出登录、退出全部设备、账号封禁与管理员禁用应用仍是独立机制；它们影响哪些凭据、后台任务是否继续，尚需确定。敏感账号操作的近期认证、学校登录能力的开通条件和内部调用的用户绑定方式，也不由免同意策略决定。

# 普通读取的授权撤销最长允许 60 秒生效

用户封禁、退出全部设备或撤销可撤销的第三方应用授权后，受相应动作影响的普通只读 API/MCP 访问最迟在 60 秒内失效；账号安全操作和学校登录能力在下一次请求检查最新状态。这个分级目标允许普通读取控制查询成本，同时收紧敏感操作。第一方授权默认生效且不能由用户单独撤销，见 [第一方授权策略](./0003-first-party-consent-policy.md)。

60 秒是容忍上限，不是必须增加缓存的要求。退出全部设备保留已启用的后台课表同步，见 [设备退出与后台同步](./0005-device-logout-and-background-sync.md)。其他动作究竟撤销哪些凭据，以及正在执行的任务如何停止，仍需后续明确；该目标也不意味着仅删除浏览器会话即可使已签发 JWT 失效。

# 设备退出、改密与账号恢复保留后台课表同步

“退出全部设备”结束浏览器、插件等设备的登录会话，但保留已启用的第一方后台课表同步。后台同步是持续提供的业务功能，不随设备退出而停止；账号封禁或解绑学校账号时，停止相应同步。

正常修改密码、通过找回重置密码以及人工恢复账号，也都保留已启用的后台同步。用户明确选择业务连续性；后台同步不能依赖会随交互登录恢复而一并撤销的设备凭据。

设备访问凭据与后台服务身份分开管理，避免为保留后台同步而让设备继续访问；后台采用 [私有 Worker RPC 服务身份](./0009-private-rpc-service-identity.md)，无需为本目标维护逐用户后台 refresh token。正常改密退出其他设备；人工恢复作废旧交互认证并生成随机新密码，后台服务身份不随之删除。正在运行任务的停止方式在相关业务边界落实。本决定只保留既有后台业务访问，不免除用户状态、业务权益及学校绑定的检查。

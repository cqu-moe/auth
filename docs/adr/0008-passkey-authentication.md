# 经用户验证的 Passkey 可独立完成登录和敏感操作认证

本轮将 Passkey 加入现有账号的可选登录方式，保留密码登录与当前注册流程，并支持同一账号绑定多个 Passkey。不在本轮新增完全无密码的注册和账号模型。

Passkey 经指纹、人脸或设备 PIN 等用户验证后，可独立完成登录，并作为敏感操作所需的近期强认证，无需再输入密码或 TOTP。服务端必须确认 WebAuthn 用户验证结果；仅用户触碰、安全密钥存在或客户端界面显示成功，不足以满足这个要求。

敏感操作继续遵守五分钟有效期，且证明必须对应当前用户和当前会话。框架的插件默认值、注册验证与登录验证需分别核实，不能把“创建了新会话”直接当成强认证已满足。Passkey 的注册、删除与恢复门禁将在具体方案中与账号安全规则统一。

人工账号恢复作废旧 Passkey 和其他旧认证方式，生成随机新密码；用户以新密码正常登录后可按需重新绑定 Passkey。普通忘记密码不删除已绑定 Passkey。具体规则见 [账号安全规则](./0006-sensitive-operation-reauthentication.md)。

# Auth 入口：校园通行证

2026-10-22，用户从基线、校园通行证、校园连接图三个可交互原型中选择「校园通行证」，并要求同时落地公开首页、登录、注册与 issue #93 的设计系统升级。基线和连接图不进入正式应用，原型选择器一并移除。

## 设计决定

- 首页采用非对称排版、蓝色色面和通行证插画，提供服务说明、开始步骤、恢复入口和社区项目身份说明。
- 登录、注册复用同一品牌顶栏和通行证介绍区；表单使用原有组件与认证逻辑，保留黑白主按钮。手机缩短介绍区，优先显示表单。
- `/` 是公开入口，不因会话检查或邮箱未验证而重定向；已有会话的开始按钮前往账号设置，设置页继续执行认证与邮箱验证门禁。
- 登录与注册互换时保留已清洗的后续跳转目标。找回密码、两步验证、OAuth、注册政策与邀请码校验继续沿用现有流程。
- 服务说明采用 180ms 透明度与 4px 位移过渡，主入口箭头提供轻量指针反馈；键盘、减少动态效果和主题切换即时完成。不加入导航入场或持续漂浮。

## 升级来源

`@cqu-moe/theme` 与 `@cqu-moe/ui` 固定到 [design v1.2.0](https://github.com/cqu-moe/design/releases/tag/v1.2.0) 的原始 tarball；校验文件保存在 `frontend/.design/SHA256SUMS`。锁文件、workspace override 同步升级。品牌素材从该 tag 的 `assets/brand/path-family/auth` 通过 `scripts/brand.mjs sync auth` 同步，检查同 tag 的完整素材 manifest。

品牌目录的 `manifest.json` 保存 tag、commit 与 13 个素材的源路径和 SHA256，已与 tag 原始字节逐一比对。

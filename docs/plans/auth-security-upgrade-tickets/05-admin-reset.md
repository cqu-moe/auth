## Parent

[Auth 安全与第一方接入升级 #41](https://github.com/cqu-moe/auth/issues/41)

## What to build

管理员在管理界面一次重置用户的全部旧认证，系统生成随机新密码并一次性返回。用户以新密码正常登录；无需受限恢复会话、额外审批工作流或强制首次改密。

## Acceptance criteria

- [ ] 操作者具备对应管理权限且完成近期强认证，目标权限层级有效；普通用户、未强认证管理员或越权目标的请求均被后端拒绝。
- [ ] 一次重置使旧密码、全部 Passkey、TOTP、恢复码、信任设备、旧交互 session、设备访问凭据及未完成旧认证/重置流程失效。
- [ ] 使用密码学安全随机源生成新密码，只保存密码哈希，在成功结果中一次性返回供管理员交付；明文不进入日志、审计或后续查询。
- [ ] 成功响应表示全部旧认证已失效且新密码已生效；故障、重试或部分完成不能误报成功，也不能留下可用的旧凭据。
- [ ] 普通用户以新密码直接正常登录，之后自主设置 Passkey/MFA；被重置的管理员仍需完成管理准入的强认证配置。
- [ ] 学校绑定、业务权益、私有 RPC 服务身份及后台同步保留，审计记录操作者、目标和结果。
- [ ] 使用真实创建的旧会话、Passkey、MFA 和设备凭据验证完整重置；检查新密码可登录、旧路径不可继续认证，以及后台 RPC 仍可执行获准操作。
